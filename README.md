# SmartGram - Village Development System

## Run
1. Open Command Prompt in this folder.
2. Run: `python -m venv venv`
3. Run: `venv\Scripts\activate` (Windows)
4. Run: `pip install -r requirements.txt`
5. Run: `python app.py`
6. Open: http://127.0.0.1:5000

## Demo accounts
Admin: admin@smartgram.local / admin123
Officer: officer@smartgram.local / officer123

Register a new citizen account from the Register page.

The database is created automatically in database/smartgram.db.
